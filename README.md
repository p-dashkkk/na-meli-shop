# На мели — интернет-магазин игрушечных кораблей

Клиент-серверное веб-приложение интернет-магазина игрушечных кораблей, разработанное в рамках курсового проекта по дисциплине «Клиент-серверные приложения».

Проект реализован по трёхслойной клиент-серверной архитектуре: **React** используется для клиентской части, **PHP** — для серверной логики, а данные хранятся в **JSON-файлах**. Взаимодействие между клиентом и сервером осуществляется через **REST API**.

## Возможности

### Для пользователя

* регистрация и авторизация;
* просмотр каталога товаров;
* фильтрация товаров по категориям;
* просмотр подробной информации о товаре;
* добавление товаров в корзину;
* удаление отдельных товаров и очистка корзины;
* просмотр итоговой стоимости;
* оформление покупки;
* сохранение корзины между сеансами с помощью `LocalStorage`.

### Для администратора

* просмотр зарегистрированных пользователей;
* удаление пользователей;
* изменение статуса наличия товаров;
* разграничение доступа по ролям;
* автоматическое обновление информации о товарах.

Функциональность каталога, корзины, авторизации и административной панели описана в отчёте проекта.

## Архитектура

Проект разделён на три основных уровня:

```text
┌─────────────────────────────┐
│       React Frontend        │
│  UI, каталог, корзина,      │
│  авторизация, AdminPanel    │
└──────────────┬──────────────┘
               │
            REST API
               │
┌──────────────▼──────────────┐
│         PHP Backend         │
│  API, бизнес-логика,        │
│  авторизация, сессии, логи  │
└──────────────┬──────────────┘
               │
┌──────────────▼──────────────┐
│        JSON Storage         │
│ users.json                  │
│ products.json               │
│ app.log                     │
└─────────────────────────────┘
```

React-приложение работает как SPA и взаимодействует с PHP-сервером посредством асинхронных HTTP-запросов. Сервер обрабатывает запросы и работает с файловым хранилищем.

## Структура проекта

```text
na-meli-shop/
├── backend/        # серверная часть на PHP
├── frontend/       # клиентская часть на React
└── pictures/       # изображения товаров
```

В репозитории также выделены отдельные директории `backend`, `frontend` и `pictures`.

### Backend

Серверная часть включает модель работы с пользователями, контроллеры и маршрутизацию REST API.

Основные операции API:

| Метод    | Маршрут                    | Назначение                     |
| -------- | -------------------------- | ------------------------------ |
| `POST`   | `/api/register`            | Регистрация пользователя       |
| `POST`   | `/api/login`               | Авторизация                    |
| `GET`    | `/api/users`               | Получение списка пользователей |
| `GET`    | `/api/users/{id}`          | Получение пользователя         |
| `DELETE` | `/api/users/{id}`          | Удаление пользователя          |
| `GET`    | `/api/products`            | Получение товаров              |
| `PATCH`  | `/api/products/{id}/stock` | Изменение наличия товара       |

Для разграничения доступа используются PHP-сессии, а действия пользователей записываются в журнал `app.log`.

### Frontend

Клиентская часть построена на React и функциональных компонентах.

Основные компоненты:

* `App.jsx` — управление приложением и взаимодействие с API;
* `ProductCard.jsx` — карточка товара;
* `Cart.jsx` — корзина;
* `AuthForm.jsx` — регистрация и авторизация;
* `AdminPanel.jsx` — административные функции.

Для управления состоянием используются React Hooks `useState` и `useEffect`.

## Хранение данных

Вместо полноценной СУБД в проекте используется файловое JSON-хранилище:

```text
backend/
└── data/
    ├── users.json
    └── products.json
```

`users.json` содержит данные пользователей и их роли, а `products.json` — каталог товаров. Пароли пользователей сохраняются в хэшированном виде с использованием `password_hash()`.

Корзина пользователя хранится в `LocalStorage`, благодаря чему её содержимое сохраняется при обновлении страницы и переходах между разделами приложения.

## Запуск проекта

### Backend

Для запуска серверной части используется **XAMPP** с веб-сервером Apache.

1. Установить XAMPP.
2. Запустить Apache.
3. Разместить проект в директории веб-сервера.
4. Убедиться, что доступна папка `backend`.
5. Запустить клиентскую часть React.

### Frontend

Перейти в директорию `frontend`, установить зависимости и запустить React-приложение:

```bash
npm install
npm start
```

> Команды запуска можно скорректировать в соответствии с `package.json` проекта.
